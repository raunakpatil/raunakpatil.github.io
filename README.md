# Raunak Patil - Interactive 3D Portfolio

Welcome to the source code for my interactive portfolio, powered by **Next.js**, **React Three Fiber**, and **Framer Motion**.

This repository contains an advanced WebGL and React-based cinematic experience that visualizes my journey as an AI Engineer and my production-grade projects.

## Architecture
- **Framework**: Next.js 14
- **3D Rendering**: Three.js / React Three Fiber / Drei
- **Animations**: Framer Motion
- **Styling**: Tailwind CSS

## Viewing the Live Site
The site is built and deployed automatically via GitHub Actions.
Visit the live portfolio here: **[https://raunakpatil.github.io/](https://raunakpatil.github.io/)**

## Setup for GitHub Pages
If you are deploying this Next.js app to GitHub Pages, ensure that:
1. Go to **Settings** > **Pages** in this repository.
2. Under **Build and deployment**, set the **Source** to **GitHub Actions**.

## Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
